# vCard Executive NFC

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)
[![4u-Labs](https://img.shields.io/badge/Ecossistema-4u--Labs-00d2ff)](https://4u.ia.br/)

Cartão de visitas executivo interativo 3D direto no navegador, com 12 temas visuais, exportação `.vcf` (vCard), QR Code dinâmico, gravação direta em tags NFC via Web NFC e modo bilíngue PT/EN.

- **Aplicativo Online:** https://4u.ia.br/app/vcard/
- **Portal 4U.IA.BR:** https://4u.ia.br/
- **Vitrine de Apps (Loja):** https://4u.ia.br/loja/
